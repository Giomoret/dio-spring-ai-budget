# Origem e atribuição

Projeto de estudo de Giovanni Alvarenga Moretto, orientado pelo desafio Spring AI da Digital Innovation One.

A organização em camadas e o fluxo de áudio/tool calling foram estudados no módulo `05-spring-ai` do repositório `digitalinnovationone/dio-spring-boot-learning-track`, commit `9add4345f9f0f75e1a02dcd557c627fdf6187ff7`. O código Java desta versão foi implementado separadamente.

Os scripts `gradlew`, `gradlew.bat` e os arquivos em `gradle/wrapper` foram aproveitados do laboratório como infraestrutura padrão do Gradle. Os scripts preservam os avisos originais de copyright e da licença Apache 2.0. Consulte também `gradle/LICENSE-wrapper.txt`.

As bibliotecas de terceiros conservam suas próprias licenças. Este aviso não concede uma licença geral sobre o restante do projeto.
